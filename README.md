# 📊 Investment Duration & Monitoring Frequency Dashboard

## 📌 Overview

This project is developed as **Task 4** of the **Cognifyz Technologies Power BI Internship**. The dashboard analyzes investors' investment durations and monitoring frequencies to understand investment behavior and preferences through interactive Power BI visualizations.

---

## 🎯 Objective

The objective of this dashboard is to:

- Analyze the distribution of investment durations.
- Examine how frequently investors monitor their investments.
- Understand the relationship between monitoring frequency and investment preferences.
- Present insights using interactive Power BI dashboards.
